# 原型怎么打开（不用找 Ports）

## 先说明：为什么找不到 Ports？

- **Ports** 一般在 **Cursor 桌面版**里，连接「远程开发 / SSH」时才会出现。
- 如果你是在 **浏览器里打开 Cloud Agent**（`cursor.com/agents/...`），**通常没有 Ports**，所以 `http://localhost:8080` 在你自己电脑上会一直 **连接被拒绝**——这是正常的，不是坏了。

---

## 办法一：下载一个 HTML，双击打开（最简单，推荐）

全部页面已经合在 **一个文件**里。下载后双击即可，购物车、结算、订单都在这个文件内部切换。

单文件：

https://github.com/Nular/lxy-misc/raw/cursor/seller-2c-product-sourcing-brainstorming-d41a/docs/prototype/product-sourcing/product-sourcing.html

或下载 ZIP（解压后只有 `product-sourcing.html`）：

https://github.com/Nular/lxy-misc/raw/cursor/seller-2c-product-sourcing-brainstorming-d41a/docs/prototype/product-sourcing/product-sourcing-html-export.zip

在线预览：

https://htmlpreview.github.io/?https://github.com/Nular/lxy-misc/blob/cursor/seller-2c-product-sourcing-brainstorming-d41a/docs/prototype/product-sourcing/product-sourcing.html

> CSS/JS 已内嵌，**不需要**安装 Python，**不需要** Ports，也**不需要**再打开其他 HTML。

---

## 办法二：在你自己电脑上 clone 后一键启动

1. 把仓库拉到本机（或只拉 `docs/prototype/product-sourcing` 目录）。

2. 终端执行：

   ```bash
   bash docs/prototype/product-sourcing/start-preview.sh
   ```

3. 用浏览器打开终端里提示的地址（一般是 `http://127.0.0.1:8080/index.html`）。

---

## 办法三：只在 Cloud Agent 虚拟机里看（给你自己排查用）

Agent 里服务已在 **8080** 跑着，但 **网页版 Agent 界面一般不能把 8080 转到你本机浏览器**。开发同事若用 **Cursor 桌面版 + 同一远程环境**，才可能在底部 **Ports** 里看到 8080。
