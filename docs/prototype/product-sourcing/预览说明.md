# 原型预览（已配置一键启动）

## 你在用 Cursor Cloud Agent 时（推荐）

1. Agent 启动后，仓库里的 `start-preview.sh` 会自动在 **8080** 端口起静态服务（见仓库根目录 `.cursor/environment.json`）。
2. 在 Cursor 界面打开 **「端口 / Ports」** 面板，找到 **8080**，点击 **「在浏览器中打开 / Open in Browser」**。
3. 若列表里没有 8080，在 Agent 对话框输入：**请运行 start-preview.sh**，或让 Agent 执行：
   ```bash
   bash docs/prototype/product-sourcing/start-preview.sh
   ```
4. 再在 Ports 里打开 8080。

**不要**在未转发端口时，只在自己电脑浏览器里输入 `http://localhost:8080`（那会连你本机，而不是 Agent 环境）。

## 你在自己电脑 clone 仓库时

在终端执行一次（保持窗口不关）：

```bash
bash docs/prototype/product-sourcing/start-preview.sh
```

然后用浏览器打开终端里打印的地址（一般是 http://127.0.0.1:8080/index.html ）。
