## 1. 背景与目标

- 背景：仓内必须先有可记账的空间结构，才能收货上架与出库推荐。
- 目标：
  - 维护仓库、三类库区、到「货架-列-层」的库位。
  - 提供 Product / SKU 库存视角与完整流水（读侧）。
- 非目标：盘库、退货、报损作业、移库作业、回写电商、采购/入出库作业（作业在另外两个一级模块）。

## 2. 范围与角色

| 角色 | 在本模块做什么 |
|---|---|
| 运营 | 建仓、维护库区库位；用查询看可用与占用 |
| 仓管 | 以上架/拣货为主；本模块以查询与流水核对 |
| 系统 | 不在本模块写库存；删除前校验库存与未完成单据 |

一期权限若来不及做，写明「全员可访问本模块，主路径仍按上表」。

## 4. 对象字典

### 4.1 仓库

| 字段 | 必填 | 说明 | 待填 |
|---|---|---|---|
| 名称 | 是 | 建议唯一 | 长度、重名文案 |
| 地址 | 是 | 规格列出 | 是否允许空？建议必填 |
| 已期初 | 否（只读） | 存在已确认期初入库单则为是 | 展示位置 |
| 创建人/时间 | — | 系统 | |

删除前置：无库存（所有库位 on_hand=0 且 locked=0）且无未完成采购/入库/出库单。

### 4.2 库区

| 字段 | 必填 | 说明 |
|---|---|---|
| 所属仓库 | 是 | |
| 类型 | 是 | 收货区 / 存储区 / 报损区；创建后不可改（待决 Q3，建议不可改） |
| 名称 | 是 | 可默认「收货区」等，允许自定义显示名 |

新建仓库时默认创建三个空库区（待决 Q6，建议是）。

### 4.3 库位

| 字段 | 必填 | 说明 |
|---|---|---|
| 仓库、库区 | 是 | 由所在节点带出 |
| 货架 | 是 | |
| 列 | 是 | |
| 层 | 是 | |
| 展示编码 | 是 | 建议系统生成，全局唯一（待决 Q1） |

唯一键：仓库 + 库区 + 货架 + 列 + 层（规格：全局唯一）。

### 4.4 库位库存（只读）

on_hand、locked、available；available = on_hand − locked。无手工编辑。

### 4.5 流水（只读）

时间、仓库、库位、SKU、数量、变更后三量、类型、关联单号、操作人。

类型一期：期初入库、采购入库、出库占用、出库扣减、取消解冻。存储预留盘盈/盘亏/报损/移库，界面不出现。

## 5. 页面需求

周四逐页写：入口、布局、字段、按钮、校验、空态、权限、跳转。

### 5.1 仓库列表

- 待填：列、排序、搜索是否要（规格未要求搜索，建议名称模糊搜）。
- 删除失败：两种原因分开文案。

### 5.2 新建 / 编辑仓库

- 待填：提交成功后是回列表还是进库区页（建议进库区，缩短建到列层路径）。

### 5.3 库区与库位

- 待填：树节点操作、批量建层是否一期做（建议一期不做批量生成，避免范围膨胀；单条新建即可）。
- 报损区：说明文案，无作业按钮。

### 5.4 库存查询

- Tab：SKU / Product。
- 筛选：仓库、库区、SKU 编码/名称、仅显示有货。
- 主表：实物、已锁定、未锁定；汇总增加途、账面。
- 下钻：仓库 / 库区 / 货架-列-层。
- 示意数据（贯穿原型）：SKU `20000MA Large Capacity Mini Comes with Four wire Power Bank-黑色`，实物 100，锁定 2，可用 98。
- 待填：仅有货的定义（建议 on_hand>0；锁定>0 而实物将随拣货变 0 的行仍应在有锁定时可见——写清「仅有货 = 实物>0 或 锁定>0」以免占用行被滤掉）。

### 5.5 库存流水

- 待填：默认时间范围（建议近 7 天）、分页、关联单号点击是否跳入出库（一期可只展示单号不跳转，减少跨模块依赖）。

## 6. 校验与文案草稿

| 条件 | 文案方向（周四润色） |
|---|---|
| 仓名重复 | 仓库名称已存在 |
| 删仓有库存 | 该仓库仍有库存，无法删除 |
| 删仓有未完成单据 | 该仓库存在未完成的采购/入库/出库单，无法删除 |
| 库位重复 | 该库位已存在（编码 xxx） |
| 删库位有库存 | 该库位仍有库存，无法删除 |
| 改有库存库位的层级 | 有库存的库位不可更改货架/列/层 |

## 7. 跨模块契约（附录，发给实习生）

直接粘贴 `02-warehouse-module.md` 第 6 节，并在周一让对方签字式确认：

- 上架可写收货区或存储区；推荐只读存储区 available>0。
- 报损区不写库存。
- 写账时点表（上架 / 占用 / 扣减 / 解冻 / 发运不写账）。
- 在途 = 已确认采购未收；草稿不计（Q8）。
- 删仓前提供 isDeletable(warehouseId)。

本模块提供：

- 库位主数据 CRUD（含类型）。
- 按仓+SKU+存储区列出 available>0 的库位（作出库推荐数据源，接口可预留，一期实现时再做；**本周原型不画该接口**）。
- 查询汇总与流水分页只读接口（实现阶段）。

## 8. 埋点与非功能（可极简）

一期建议只写：列表需支持一个仓下数百库位仍可浏览；无路径优化。不写性能指标数字除非评审要求。

## 9. 验收用例（仓库管理可独立的）

1. 新建仓库（名称、地址）成功出现在列表。
2. 自动或手动具备收货区、存储区、报损区。
3. 在存储区建到货架-列-层；重复五段被拦截。
4. 报损区可见且无报损操作。
5. 无库存无单据时可删仓；有库存或未完成单据时不可删。
6. 查询页存在 SKU / Product 两个视角与规定筛选（无数据时空态正确）。
7. 流水页具备一期五类类型筛选，无盘盈盘亏等入口。
8. 全产品导航无盘库、退货、回写电商。

联调用例（依赖入出库，本 PRD 只列对照，不作为本周原型必点）：

- 上架后查询未锁定与实物增加，流水为采购入库或期初入库。
- 出库确认后锁定增加、未锁定减少；拣货后实物与锁定同减；关单解冻；发运三量不变。
- 同一 SKU 在收货区有货时，查询看得到，但出库推荐不应选到该库位（由出库验收）。
