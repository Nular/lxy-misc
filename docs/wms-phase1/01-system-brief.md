# 微型仓 WMS 一期 · 系统信息梳理

日期：2026-08-20  
依据：一期设计说明 + 8/20 本侧需求变更  
产品正文：[05-warehouse-prd.md](./05-warehouse-prd.md)

## 1. 系统是什么

独立微型仓执行系统，与 C 端作业解耦。商品只读电商库，WMS 不建品，库存不回写可售。订单：C 端 Excel → 人工分 parcel → 导入 WMS。

**8/20 起记账精度：仓库 → 库区。本期不做货架 / 列 / 层。**

## 2. 模块与分工

```text
设置（本侧）
├── 仓库管理（仓库 ID、属性、状态、标准化地址等；新建停用；自带 3 库区）
└── 仓库库区管理（八类库区；默认三区不可删）

库存查看（本侧）
├── SPU 视图
└── SKU 视图（条码扩展：欧洲码优先 / 美国码 / 平台码）

库存流水（本侧只读）
├── 入库 / 采购单 / 出库占用 / 出库扣减 / 解冻
└── 采购单流水由采购单模块写入；采购单页面本侧不做

入库（实习生）含采购收货与期初；采购单作业他人负责
出库（实习生）预检 → 推荐存储区 → 确认占用 → 拣货扣减 → 打包发运只改状态
```

## 3. 约束摘要

| 项 | 结论 |
|---|---|
| 精度 | 仓库 + 库区 |
| 库区 | 八类；新建自带收货、存储、待发货；最多 8 个；同仓同类型至多 1 |
| 仓库状态 | 新建停用，管理员编辑页启用 |
| 实物口径 | 实物 = 已锁定 + 未锁定 |
| 在途 / 账面 | 本期不做 |
| 出库推荐 | 启用中的存储区且 available>0 |
| 冻结 | 出库确认导入后改数量 locked；冻结区只建档 |
| 扣减 | 拣货确认；打包/发运不改库存 |
| 日常入库 | 必须有采购单 |
| 期初 | 每仓一次 |
| 预检 | 全过才确认 |

## 4. 核心对象

| 对象 | 要点 |
|---|---|
| 仓库 | ID 创建后不可改；属性普通/防火/恒温/冷链；标准化地址；坐标/面积/层高/合规/负责人/联系人 |
| 库区 | 编码、类型、状态 Tag |
| 库存 | 仓库 × 库区 × SKU 的 on_hand / locked / available |
| SKU 副本 | 只读；条码类型+值扩展 |
| 采购单 | 本侧不做页面；写采购单流水 |
| 入出库单 | 建议/确认库区（不再是列层） |
