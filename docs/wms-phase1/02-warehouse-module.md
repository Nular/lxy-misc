# 本侧模块 · 分析与总结（同步 PRD v0.10）

日期：2026-08-20  
产品正文：[05-warehouse-prd.md](./05-warehouse-prd.md)

## 1. 定位

设置里管空间主数据；库存查看与流水是读侧。不写账、不做采购单作业、不做货架列层。

## 2. 子功能

| 子功能 | 说明 |
|---|---|
| 仓库管理 | 宽表单 + 状态 Tag + 双击库区数量进库区 |
| 仓库库区管理 | 八类；默认三区不可删；最多 8 |
| 库存查看 | SPU / SKU；无在途账面；分布到库区 |
| 库存流水 | 五 Tab；采购单流水只展示 |

## 3. 库区与推荐

出库推荐只走启用存储区。收货区可暂存上架。待发货/打包/退货/冻结/报损/特殊本期只建档。冻结区 ≠ 库存 locked。

## 4. 给入出库 / 采购单的契约

| 事件 | 库存三量 | 流水 |
|---|---|---|
| 上架确认 | 实物↑ 未锁定↑ | 入库 |
| 采购单状态/已收未收 | 不变 | 仅采购单流水 |
| 出库确认导入 | 锁定↑ 未锁定↓ | 出库占用 |
| 拣货 | 实物↓ 锁定↓ | 出库扣减 |
| 关单解冻 | 锁定↓ 未锁定↑ | 解冻 |
| 打包发运 | 不变 | 不写 |

上架目标：启用收货区或存储区。推荐：启用存储区 available>0，粒度为库区。

删仓：无库存且无未完成采购/入出库单。默认可编辑不可删，用停用表示「不需要」。

条码：副本预留欧洲码/美国码/平台码，展示欧洲码优先。WMS 不维护条码主数据。
