# 仓库管理模块 · 分析与总结

日期：2026-08-19  
模块范围：一期一级模块「库存管理」  
负责人：仓库管理（本侧）  
协作：入库、出库由另外两名实习生实现；本侧给出主数据与库存读模型契约

## 1. 模块定位

仓库管理是微型仓的 **空间主数据 + 库存读侧**。

- **主数据**：仓库、库区、库位。没有这些对象，入库无处上架，出库无处推荐。
- **读侧**：按 Product / SKU 查实物、锁定、未锁定；按流水追溯到单号与库位。
- **不负责写账**：上架增库存、出库冻结/扣减/解冻由入出库在确认动作里完成，并按本模块定义的流水类型落账。

一期不做盘库、移库作业、报损作业。报损区只建档。

## 2. 子功能拆分

| 子功能 | 独立程度 | 周一原型优先级 | 说明 |
|---|---|---|---|
| 仓库管理 | 高，可独立交付 | P0 | 名称、地址；列表/创建/编辑/删除 |
| 库区与库位 | 高，可独立交付 | P0 | 三类库区；货架-列-层；全局唯一 |
| 库存查询 | 中，依赖入出库写账 | P0 出页面与空态；数字联调后验 | 两种视角、下钻、筛选 |
| 库存流水 | 中，依赖入出库写流水 | P0 出页面与字段；数据联调后验 | 只读列表，不允许手工改账 |

建议对外沟通时拆成两段交付：

1. **主数据（可先验收）**：仓 / 区 / 位。
2. **账本读侧（联调验收）**：查询 + 流水；页面与口径先定，数据等入出库写入。

## 3. 对象与层级

```text
仓库
 └── 库区（收货区 | 存储区 | 报损区）
      └── 库位 = 仓库 + 库区 + 货架 + 列 + 层   （全局唯一）
           └── 库位库存（SKU × 库位）：on_hand / locked / available
```

### 3.1 仓库

- 字段：名称、地址。
- 行为：创建、列表、编辑、删除。
- 删除：有 **库存** 或 **未完成采购单 / 入库单 / 出库单** 时拒绝。
- 期初标记不在仓库表单上维护：以「该仓是否已存在类型=期初且已确认的入库单」为准（入库模块写入，本模块查询侧只读该事实）。

### 3.2 库区

- 隶属一个仓库。
- 类型固定三种：收货区、存储区、报损区。
- 出库推荐 **只读存储区**。
- 收货区：允许作为实际上架库位；查询可见；推荐忽略。
- 报损区：可建、可出现在库位树；一期无「移入报损」按钮，推荐忽略。

### 3.3 库位

- 组成：仓库 + 库区 + 货架 + 列 + 层。
- 库存只记在库位，不记在仓库或库区汇总表（汇总是查询计算）。
- 入库建议库位：该 SKU 在本仓库 **存储区** 最近一次成功上架的库位；无历史则空，必须人选或 Excel 给出。规则由入库执行，本模块提供「可被查询的存储区库位」。

规格未写死库位编码格式。PRD 建议补一条 **展示编码**（例如 `仓编码-区类型-货架-列-层`），编码参与全局唯一校验，避免「一号货架」在不同仓撞名时无法辨认。编码规则是展示与校验设计，不改变五段层级。

### 3.4 库位库存（读模型）

每个库位 × SKU 一行：

| 字段 | 含义 | 公式 / 来源 |
|---|---|---|
| on_hand | 实物 | 已锁定 + 未锁定 |
| locked | 已锁定（订单占用） | 出库确认导入后增加，拣货或关单减少 |
| available | 未锁定（可用） | on_hand − locked |

查询汇总：

| 口径 | 计算 | 展示位置 |
|---|---|---|
| 实物 | 各库位 on_hand 之和 | SKU / Product / 仓 / 区 |
| 已锁定 | 各库位 locked 之和 | 同上 |
| 未锁定 | 各库位 available 之和 | 同上 |
| 在途 | 该仓该 SKU 采购未收数合计 | **不下钻到库位**；来自入库采购单 |
| 账面 | 实物 + 在途 | SKU / Product 汇总；库位行不显示在途 |

库存查询筛选：仓库、库区、SKU 编码/名称、仅显示有货。

下钻：SKU 视角一行一个 SKU → 仓库 → 库区 → 货架-列-层。Product 视角先按 Product 汇总其下 SKU，再同样下钻。

## 4. 页面清单（建议原型范围）

### 4.1 仓库列表

- 列：名称、地址、库区数、库位数、是否已期初（只读）、创建时间。
- 操作：新建、编辑、删除（不满足条件时按钮可用但提交失败并提示原因）。
- 空态：尚无仓库，引导先建仓。

### 4.2 仓库详情 / 编辑

- 名称、地址。
- 入口进入「库区与库位」。
- 不在此页做入库、出库。

### 4.3 库区与库位

建议 **左树右表**：

- 左：仓库 → 三类库区 → 货架。
- 右：当前节点下的列-层列表；新建库位（货架、列、层）；编辑名称段；删除空库位。
- 库区类型创建时选定，一期不建议改类型（避免收货区改存储区后出库推荐口径被悄悄改掉）。
- 报损区节点旁可用文案标明「一期仅建档，不做出库推荐、不做报损作业」，不要放报损按钮。

### 4.4 库存查询

- Tab：SKU 视角 / Product 视角。
- 筛选条：仓库、库区、关键词、仅有货。
- 主表三量：实物、已锁定、未锁定；汇总层加在途、账面。
- 行展开或下钻页：仓 → 区 → 库位。
- 无数据：区分「未建仓」与「有仓无库存」。

### 4.5 库存流水

- 筛选：时间、仓库、库位、SKU、类型、关联单号、操作人。
- 列：时间、仓库、库位、SKU、数量、变更后实物/锁定/可用、类型、关联单号、操作人。
- 一期类型枚举只展示这五项（存储可扩展，界面不开放盘盈盘亏报损移库）。
- 只读，无「手工调账」。

## 5. 规则与异常（本模块负责拦截的）

| 场景 | 处理 |
|---|---|
| 删除仓库，仍有库位库存（on_hand>0 或 locked>0） | 拒绝，提示有库存 |
| 删除仓库，存在未完成采购/入库/出库单 | 拒绝，提示未完成单据（单据状态定义见入出库，本模块按契约询问） |
| 库位五段组合重复 | 拒绝，提示全局已存在 |
| 库位有库存时删除库位 | 拒绝（规格只写了删仓；库位对齐同一原则） |
| 库位被未完成入出库行引用 | 拒绝删除 |
| 新建库位时库区类型非法 | 拒绝（只能落在已有三类库区下） |
| 仓库已期初 | 本模块不提供「再做期初」入口；拒绝逻辑在入库 |

规格未写但建议在 PRD 写死、不改变拍板结论的补强：

- 库区类型创建后不可改。
- 有库存的库位不可改所属库区（可改展示名若编码不变；若编码含区类型则禁止改区）。
- 仓库名称建议仓内唯一，避免运营选仓选错。

## 6. 给入出库实习生的契约（本模块定义，对方遵守）

仓库管理不实现入出库，但必须把下面几条写成对方 PRD 的输入，否则查询数字会对不上。

### 6.1 库位使用

| 动作 | 允许的库区 |
|---|---|
| 入库实际上架 | 收货区、存储区 |
| 入库历史建议 | 仅存储区，最近一次成功上架 |
| 出库推荐与确认冻结 | 仅存储区且 available>0 |
| 报损区 | 任何作业都不要写入库存 |

### 6.2 写账时点（只陈述已拍板，供查询对照）

| 事件 | on_hand | locked | available | 流水类型 |
|---|---|---|---|---|
| 期初/采购确认上架 | ↑ | — | ↑ | 期初入库 / 采购入库 |
| 出库确认导入 | — | ↑ | ↓ | 出库占用 |
| 拣货确认 | ↓ | ↓ | — | 出库扣减 |
| 关闭已占用出库单 | — | ↓ | ↑ | 取消解冻 |
| 打包/发运 | 不变 | 不变 | 不变 | 不写库存流水 |

打包/发运只改出库单状态。查询页在发运后实物应已在拣货时减掉，三量不再因发运变化。

### 6.3 出库推荐数据源

本模块保证能列出：指定仓库 + 指定 SKU + 库区类型=存储区 + available>0 的库位，按 available 从大到小。拆行策略（一行一个库位）由出库模块做，不在仓库管理做路径优化。

### 6.4 删除仓前的「未完成单据」

由入出库提供只读判断，建议未完成定义为：

- 采购单：非已完成、非已关闭。
- 入库单：未确认上架（具体状态名由入库 PRD 对齐）。
- 出库单：非已发运、非已关闭（已占用/已拣货/已打包仍算未完成，不可删仓）。

本模块删除时调用该判断，不自己扫业务表字段名。

### 6.5 查询用的在途

`在途(仓库, SKU) = Σ 已确认采购单该行未收数`（草稿采购单是否计入，建议 **不计入**；以入库 PRD 最终状态机为准，本侧默认已确认及之后、未关闭）。

账面不在库位行展示，避免运营以为在途已经落在某一层。

### 6.6 商品

仓库管理列表不维护商品。查询与流水展示 SKU/Product 名称时读本地副本；副本由入出库预检写入。本模块不在电商不可达时静默造品。

## 7. 与一期验收的对应

规格第 9 节中，仓库管理直接对应：

- 能建仓库、三类库区、库位到列层。
- 库存查询两种视角数字正确（联调后）。
- 流水能追溯到单号与库位（联调后）。
- 不出现盘库、退货作业入口。
- WMS 不写回电商库存（本模块无同步按钮）。

其余验收项（采购分次收、Excel 预检、期初一次、出库冻结/扣减/解冻、打包不改库存）由入出库交付，本模块用查询/流水做对照验收，不重复做作业界面。

## 8. 非目标（界面上要看不见）

- 盘库、移库、报损作业、退货入库、无单日常入库。
- 可售数量推送电商。
- 拣货路径、波次。
- 手工改 on_hand / locked。
- 把采购单做成与库存管理并列的一级菜单。

## 9. 风险（给周一评审用）

1. **模块名混用**：规格叫库存管理，日常叫仓库管理。PRD 标题建议「库存管理（仓库 / 库区 / 库位 / 查询 / 流水）」，菜单一级名与规格一致。
2. **实习生写账口径不一致**：必须把第 6 节契约先发给对方，再让对方写 PRD。
3. **收货区库存**：允许存在，但出库推荐不到。查询需能解释「有实物但不可被出库推荐」。
4. **在途不下钻库位**：避免原型把在途画进库位行。
5. **删仓联动**：未完成单据定义要在周一评审时与入出库对齐，否则删除提示无法实现。
