## 1. 背景与目标

仓内实物记到「某仓库的某库区」。本侧提供仓库与库区主数据、库存只读查看、流水只读对账。增减与占用由入库 / 出库写入；采购单作业由他人交付，本侧只展示采购单流水。

**本侧一期目标：**

- 在设置中维护仓库与最多八类库区；新建仓带出三个默认库区。
- 库存查看分 SPU / SKU，数字为实物 / 已锁定 / 未锁定，可下钻到库区。
- 流水可按入库、采购单、出库占用、出库扣减、解冻查阅。

**非目标：** 货架-列-层、在途/账面、盘库作业、退货作业界面、报损作业、移库、无单日常入库、波次路径、回写电商、手工调账、采购单作业页（本侧）。

可建「退货区 / 报损区 / 冻结区」不等于本期做退货、报损、移入冻结区作业。

## 2. 角色与权限

| 角色 | 主路径 |
|---|---|
| 运营 | 设置中建仓、管库区；库存查看与流水核对 |
| 仓管 | 以库存查看、流水为主 |
| 管理员 | 在仓库编辑页将状态从停用改为启用 |

启用仓库需要管理员。其余一期不做更细按钮权限；无管理员角色时，编辑页仍展示状态开关，但文案标明「需管理员启用」。

商品只读电商库。SKU 条码只缓存与展示扩展，不在 WMS 建品、不在 WMS 维护条码主数据。

## 4. 全局口径与对象

### 4.1 数量口径

| 名称 | 定义 | 本期 |
|---|---|---|
| 实物 `on_hand` | 已锁定 + 未锁定 | 库存查看、流水变更后 |
| 已锁定 `locked` | 出库确认导入后占用，尚未拣货或尚未关单 | 同上 |
| 未锁定 `available` | `on_hand − locked` | 同上 |
| 在途、账面 | — | **本期不做，界面不出现这两列** |

账一行 = **仓库 × 库区 × SKU**。不再有货架/列/层库存行。

**库存锁定 ≠ 冻结区：** 出库占用改的是数量字段 `locked`；库区类型「冻结区」是空间分类，一期无「移入冻结区」作业。

### 4.2 空间对象

```text
仓库（仓库 ID 唯一且创建后不可改）
 └── 库区（八类之一；同仓每种类型至多 1 个；每仓最多 8 个）
```

八类库区：

| 类型 | 类型码 | 新建仓是否自带 | 可否删除 | 本期作业 |
|---|---|---|---|---|
| 收货区 | RCV | 是 | 否（默认库区） | 允许上架暂存；出库不推荐 |
| 存储区 | STO | 是 | 否 | 上架建议与出库推荐只走这里 |
| 待发货区 | SHP | 是 | 否 | 建档；打包/发运仍只改单据状态，不强制移区 |
| 打包区 | PKG | 否，可加 | 无库存且未被引用则可删 | 仅建档 |
| 退货区 | RTN | 否，可加 | 同上 | 仅建档，无退货作业 |
| 冻结区 | HLD | 否，可加 | 同上 | 仅建档；与库存 `locked` 不是一回事 |
| 报损区 | DMG | 否，可加 | 同上 | 仅建档，无报损作业 |
| 特殊区 | SPC | 否，可加 | 同上 | 仅建档 |

说明：需求原文「前三个区如果不需要可以删除、编辑」与「三大默认库区不可删除」并存。本版落地为：**三个默认库区可编辑（名称、状态），不可删除**；不需要的后五类可以不建，已建的可删（满足空区条件）。若评审改为默认可删，再改 v1.0。

### 4.3 SKU 条码扩展（只留口，不单独做条码模块）

本地商品副本上为每个 SKU 预留多条条码：

| 字段 | 说明 |
|---|---|
| 条码类型 | `欧洲码`（优先）/ `美国码` / `平台码`（seller 端） |
| 条码值 | 对应类型下的码值 |

规则：同一 SKU 同一类型至多一条；展示时 **欧洲码优先**，无欧洲码再美国码，再平台码。本期库存查看 SKU 行可展示「主条码」一列；不提供条码增删改页面。数据来自电商只读同步/预检缓存。后续可加类型而不改库存结构。

### 4.4 仍待与入出库对齐（不阻塞本侧页面）

| 编号 | 项 | 本版默认 |
|---|---|---|
| A1 | 停用仓库 | 不可作为新入出库作业仓；已有库存仍可在库存查看中看到 |
| A2 | 停用库区 | 不可作为新上架/推荐目标；已有库存仍展示 |
| A3 | 库区类型创建后 | 不可改类型、不可改库区编码 |
| A4 | 同仓同类型 | 至多一个 |
| A5 | 未完成单据 | 采购非已完成/已关闭；入库未确认上架；出库非已发运/已关闭 |

## 5. 设置 · 仓库管理

维护仓库主数据。创建时带出初始库区。不在此页写库存。

### 5.1 仓库列表

**入口：** 设置 → 仓库管理。

**页头：** 标题「仓库管理」+「创建仓库」。

**筛选：** 仓库 ID、名称（模糊）、属性、状态（全部/启用/停用）。

**列表列：**

| 列 | 说明 |
|---|---|
| 仓库 ID | 唯一，创建后不可改 |
| 名称 | |
| 属性 | 普通 / 防火 / 恒温 / 冷链 |
| 状态 | **Tag**：启用（绿）/ 停用（灰） |
| 库区数量 | 只读计数；**双击进入该仓「仓库库区管理」** |
| 标准化地址 | 国家 + 省/州 + 市/县 + 详细地址拼成一行，过长省略 |
| 负责人 | |
| 联系人 / 电话 | |
| 操作 | 编辑、删除 |

坐标、面积、层高、合规不进默认列表，在编辑页查看。列表不展示已期初（期初控制仍在入库模块）。

**交互：**

- 单击行或「编辑」→ 编辑仓库。
- **双击「库区数量」单元格** → 仓库库区管理，并带上该仓库 ID 筛选。编辑表单中的库区数量同样支持双击跳转。
- 单击库区数量不跳转，避免误触。

**空态：** 「还没有仓库」+「创建仓库」。  
**分页：** 20 条。默认创建时间倒序。

**删除按钮**始终展示；不满足条件时点击后提示原因。

---

### 5.2 创建仓库

**入口：** 列表「创建仓库」。全页表单。

**字段：**

| 字段 | 必填 | 约束 |
|---|---|---|
| 仓库 ID | 是 | 4–20 位，字母数字和 `-` `_`；全系统唯一；**提交后不可改** |
| 名称 | 是 | 2–50 字，去首尾空格；建议全系统唯一 |
| 属性 | 是 | 单选：普通 / 防火 / 恒温 / 冷链 |
| 状态 | — | 只读展示 Tag「停用」；创建页不可改为启用 |
| 库区数量 | — | 只读，创建前显示「将自动生成 3 个」 |
| 国家 | 是 | 文本或下拉，1–50 字 |
| 省/州 | 是 | 1–50 字 |
| 市/县 | 是 | 1–50 字 |
| 详细地址 | 是 | 到门牌号，1–200 字 |
| 坐标 | 否 | 经度、纬度两个数字；填则须成对、在合法范围 |
| 面积 | 否 | 数字，单位 ㎡，≥0 |
| 层高 | 否 | 数字，单位 m，≥0 |
| 称重合规 | 否 | 是 / 否 / 未填；默认未填 |
| 消防合规 | 否 | 是 / 否 / 未填；默认未填 |
| 负责人 | 否 | 1–50 字 |
| 联系人 | 否 | 1–50 字 |
| 联系电话 | 否 | 1–30 字；填了联系人建议同时填电话 |

创建页不选手动勾选初始库区。提交成功后系统生成：

1. 仓库，状态=停用。
2. 三个库区：收货区、存储区、待发货区；状态默认启用；编码见 6.2。
3. Toast：「仓库已创建（停用）。已生成 3 个默认库区。请管理员启用后再用于作业。」
4. 跳转：该仓编辑页，或该仓库区列表（原型用库区列表，便于核对初始库区）。

**校验文案（摘）：**

| 条件 | 文案 |
|---|---|
| 仓库 ID 空 | 请填写仓库 ID |
| 仓库 ID 重名 | 仓库 ID 已存在 |
| 名称为空 | 请填写仓库名称 |
| 地址段缺失 | 请完整填写国家、省/州、市/县和详细地址 |
| 只填经度或纬度 | 请同时填写经度、纬度，或都留空 |

### 5.3 编辑仓库 / 删除仓库

#### 5.3.1 编辑

**入口：** 列表「编辑」。

**不可改：** 仓库 ID。  
**可改：** 名称、属性、标准化地址、坐标、面积、层高、两项合规、负责人、联系人、电话。  
**状态：** Tag。停用 → 启用 **仅管理员** 可操作；启用 → 停用同样建议仅管理员。非管理员看到禁用的状态开关 + 说明。

**库区数量：** 只读；**双击**跳转仓库库区管理（该仓）。旁可放文字链「管理库区」。

不在编辑页直接增删库区行（避免与库区模块两套表单）。

成功 Toast：「仓库已更新」。启用成功额外一句：「仓库已启用，可用于入出库作业。」

#### 5.3.2 删除

列表「删除」→ 确认：「确定删除仓库「{名称}」（{仓库 ID}）？其下库区将一并删除且不可恢复。」

| 顺序 | 条件 | 文案 |
|---|---|---|
| 1 | 任一库区该仓 `on_hand>0` 或 `locked>0` | 该仓库仍有库存，无法删除 |
| 2 | 存在未完成采购/入库/出库单 | 该仓库存在未完成的采购/入库/出库单，无法删除 |

通过则删除仓库及其库区。停用不是删除。删除不要求先停用，但有库存仍拒绝。

## 6. 设置 · 仓库库区管理

**侧栏：** 设置 → 仓库库区管理。

### 6.1 库区列表

**筛选：** 仓库 ID、库区编码、库区类型、状态。

从仓库「库区数量」双击进入时，仓库 ID 筛选项锁定为该仓，可清除后看全部。

**列：**

| 列 | 说明 |
|---|---|
| 仓库 ID | |
| 库区编码 | 仓内唯一 |
| 库区类型 | 八类之一，徽章 |
| 状态 | Tag：启用 / 停用 |
| 操作 | 编辑、删除 |

可补充显示名列（默认同类型名，可编辑），便于「特殊区」改成业务别名；列表以需求四列为准，显示名放编辑表单必填。

**页头：** 「添加库区」。当前仓已满 8 个或八类都已有时，按钮禁用，悬停：「每个仓库最多 8 个库区，且每种类型只能有一个」。

**空态：** 未选仓且系统无库区（尚无仓库）→ 引导先创建仓库。

### 6.2 创建库区

| 字段 | 必填 | 规则 |
|---|---|---|
| 仓库 ID | 是 | 下拉已有仓库；从某仓跳入则锁定 |
| 库区类型 | 是 | 仅列出该仓尚未使用的类型 |
| 库区编码 | 是 | 默认 `{仓库ID}-{类型码}`，可改；同一仓库内唯一；创建后不可改 |
| 显示名 | 是 | 默认等于类型名，1–20 字 |
| 状态 | 是 | 默认启用 |

新建仓库自动创建的三条：

| 类型 | 默认编码示例（仓库 ID=`WH01`） |
|---|---|
| 收货区 | `WH01-RCV` |
| 存储区 | `WH01-STO` |
| 待发货区 | `WH01-SHP` |

后五类由本表单添加。不得突破 8 个、不得类型重复。

### 6.3 编辑库区

可改：显示名、状态。  
不可改：仓库 ID、库区编码、库区类型。

停用库区：已有库存仍留在该区并在库存查看中可见；新上架/出库推荐不得再指向该区。

### 6.4 删除库区

二次确认后校验：

| 条件 | 处理 |
|---|---|
| 类型为收货区 / 存储区 / 待发货区 | **不可删除**：「默认库区不可删除，可改为停用」 |
| 有库存 | 「该库区仍有库存，无法删除」 |
| 被未完成入出库行引用 | 「该库区存在未完成的入库/出库行，无法删除」 |
| 其余 | 删除成功 |

三个默认库区用停用代替删除，对应「不需要时」的处理。

无报损作业、退货作业、移入冻结区按钮。

## 7. 库存查看

原「库存管理 / 仓库查询」更名为 **库存查看**。只读。本期无在途、无账面。

贯穿示意：

```text
SKU: 20000MA Large Capacity Mini Comes with Four wire Power Bank-黑色
实物 100    已锁定 2    未锁定 98
主条码：欧洲码 {值}（无则美国码，再平台码）
```

**入口：** 一级「库存查看」。页内 Tab：`SPU` | `SKU`。

### 7.1 共用筛选

| 项 | 规则 |
|---|---|
| 仓库 | 全部 / 指定；可含停用仓（看历史库存） |
| 库区 | 全部 / 指定类型或指定库区 |
| 关键词 | SPU Tab 匹配 SPU 编码/名称；SKU Tab 匹配 SKU 编码/名称/条码值 |
| 仅显示有货 | 默认关；开：实物>0 或已锁定>0 |

### 7.2 SPU 视图

一行一个 SPU，数量为其下 SKU 在筛选范围内合计。

列：SPU 编码、名称、SKU 数、实物、已锁定、未锁定、操作「分布」。

点击 SPU：展开其下 SKU 子表（列同 7.3，可少条码列）。点某一 SKU「分布」进入 7.4。不可从 SPU 行直接到库区（账按 SKU 记）。

空态：无仓 / 无库存 / 筛选无匹配，三种文案分开。

### 7.3 SKU 视图

一行一个 SKU。

| 列 | 说明 |
|---|---|
| SKU 编码 | |
| SKU 名称 | |
| SPU | 所属 SPU |
| 主条码 | 类型 + 值，欧洲码优先；都无则 — |
| 实物 / 已锁定 / 未锁定 | 筛选范围内库区合计 |
| 操作 | 分布 |

未锁定必须等于 实物 − 已锁定。无修正按钮。分页 20，默认实物倒序。

条码：主条码列即扩展位；不在本期做多码管理弹窗。悬停可显示该 SKU 已缓存的全部类型（有则列出欧洲码/美国码/平台码）。

### 7.4 库存分布详情

从 SPU 子表或 SKU 行「分布」进入，不进侧栏。

页头：SKU 编码、名称、主条码；汇总实物/锁定/未锁定；返回。

只下钻两层：

1. **仓库**：该 SKU 各仓三量。
2. **库区**：仓下各库区三量；类型徽章。收货区说明「不参与出库推荐」。报损/退货/冻结/打包/特殊/待发货：一期无对应作业，仅展示若已有库存。

**没有** 货架、列、层。

可选：「查看该库区流水」跳转库存流水并带 SKU+仓库+库区筛选。

## 8. 库存流水

只读。禁止手工调账。盘盈盘亏报损移库不出现。打包/发运不写任何 Tab。

**入口：** 库存流水。五个 Tab。共用筛选：时间（默认近 7 天）、仓库、库区、SKU、关联单号、操作人。

**库存类流水共用列：** 时间、仓库、库区（编码+类型）、SKU、数量、变更后实物/锁定/未锁定、类型、关联单号、操作人。  
关联单号一期只展示文本，不强制跳转对方详情。

账记在库区，列名是库区不是库位。

### 8.1 入库流水

类型：`期初入库`、`采购入库`。子筛：全部 / 期初 / 采购。  
写账：入库确认上架后。实物↑、未锁定↑。关联入库单号；采购入库可附采购单号（次要信息）。

### 8.2 采购单流水

**本侧不做采购单页面。** 本 Tab 展示采购单模块写入的审计流水。

**不改库区库存。** 与「采购入库」（上架写库存）分开，避免把下单未收当成已入库存。

建议列：时间、采购单号、仓库、SKU、事件、采购数、已收数、未收数（变更后）、操作人。无库区列（采购行不写库区）。

事件建议（由采购单模块落地，本侧按这些展示）：创建、确认、部分入库回写、已完成、已关闭。草稿是否落流水由采购单模块定，建议确认后才出现。

空态：「暂无采购单流水」。无「创建采购单」按钮（避免做成作业入口）。

### 8.3 出库占用流水

类型 `出库占用`。确认导入后：未锁定↓、已锁定↑、实物不变。关联出库单号。预检零流水。整单失败不写半截。

### 8.4 出库扣减流水

类型 `出库扣减`。拣货确认：锁定↓、实物↓。打包/发运不写。

### 8.5 解冻流水

类型 `取消解冻`。关闭已占用出库单：锁定↓、未锁定↑。Tab 名「解冻」。

## 9. 跨模块契约

### 9.1 库区写入（入出库遵守）

| 动作 | 允许 |
|---|---|
| 入库实际上架 | 启用中的收货区或存储区 |
| 入库历史建议 | 该 SKU 本仓存储区最近一次成功上架（本期即该仓唯一存储区） |
| 出库推荐与确认占用 | 启用中的存储区且 available>0 |
| 待发货 / 打包 / 退货 / 冻结 / 报损 / 特殊 | 本期作业不要写入库存 |
| 停用仓、停用库区 | 不可作为新作业目标 |

推荐粒度：仓库 + 库区，不再拆货架列层。每仓存储区至多一个，出库推荐不再拆多库位行；数量仍不能超过该存储区 available。

### 9.2 写账与流水 Tab

| 事件 | 实物 | 锁定 | 未锁定 | 流水 |
|---|---|---|---|---|
| 期初/采购确认上架 | ↑ | — | ↑ | 入库 |
| 采购单创建/确认/关单/回写已收未收 | 不变 | 不变 | 不变 | **仅采购单流水** |
| 出库确认导入 | — | ↑ | ↓ | 出库占用 |
| 拣货确认 | ↓ | ↓ | — | 出库扣减 |
| 关闭已占用出库单 | — | ↓ | ↑ | 解冻 |
| 打包/发运 | 不变 | 不变 | 不变 | 不写 |

采购单模块负责写 8.2；入库确认仍写 8.1，不要用采购单流水替代上架。

### 9.3 本侧提供

- 仓库 / 库区主数据；出库推荐：指定仓 + SKU + 类型=存储区 + 启用 + available>0。
- 删仓前：无库存且对方返回无未完成单据。
- SKU 副本含条码扩展；预检仍须能解析 SKU。

### 9.4 采购单（他人）须知

作业页面不在本 PRD。须向库存流水写入采购单事件；已收未收变化若发生在上架确认，应同时有入库流水（库存）和采购单流水（单据数量快照），两者单号可互查。

## 10. 验收用例

1. 创建仓库须填仓库 ID 与标准化地址；提交后状态=停用，且自动 3 个默认库区（收货/存储/待发货）。
2. 非管理员不能启用仓库；管理员可在编辑页启用。
3. 可再添加打包/退货/冻结/报损/特殊，总数≤8，类型不重复；默认可编辑、不可删；后五类空区可删。
4. 列表或编辑中双击库区数量进入该仓库库区管理。
5. 库区列表含仓库 ID、库区编码、类型、状态 Tag；支持添加/编辑/删除（删除受 6.4 约束）。
6. 任何页面不出现货架、列、层。
7. 库存查看仅 SPU / SKU；无在途、账面；示意 100 / 2 / 98；分布只到库区。
8. SKU 行具备主条码扩展位（可为空）。
9. 流水五个 Tab；采购单 Tab 无创建采购单按钮；发运不增库存流水。
10. 无盘库、退货作业、报损作业、回写电商入口。

## 11. 非功能

单仓最多 8 库区，列表无需为海量库位做树。流水默认近 7 天。
