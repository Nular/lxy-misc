## 1. 背景与目标

跨境零售配套的独立微型仓需要把实物记到「仓库 → 库区 → 货架 → 列 → 层」。本模块提供空间主数据，以及按 SKU 看库存、按下钻看分布、按类型看流水的读侧页面。库存增减、冻结、解冻由入库 / 出库模块在确认动作里写入，本模块不提供手工调账。

**一期目标：**

- 能创建、维护仓库；每个仓具备收货区、存储区、报损区；库位建到列层且全局唯一。
- 能从 SKU（及拍板要求的 Product 汇总）看到实物 / 已锁定 / 未锁定，并能下钻到库位分布。
- 能按入库、出库占用、出库扣减、解冻查看流水，追溯到单号与库位。

**非目标（界面不得出现入口）：** 盘库、退货作业、报损作业、移库、无单日常入库、波次/路径优化、可售回写电商、采购单一级菜单、手工改库存。

---

## 2. 角色与权限

| 角色 | 本模块主路径 |
|---|---|
| 运营 | 仓库列表 / 创建 / 编辑删除 / 库区与库位；用仓库查询与流水核对 |
| 仓管 | 以查询、流水核对为主（上架、拣货在入库 / 出库模块） |

一期不做按钮级权限：登录用户均可进入本模块。主路径仍按上表描述。商品主数据只读电商库，本模块不建品。

## 3. 信息架构

系统一级导航与规格一致：`库存管理` / `入库` / `出库`。入库、出库仅占位，本 PRD 不画作业页。

库存管理内按三大模块组织：

```text
库存管理
├── 仓库管理
│   ├── 仓库列表
│   ├── 创建仓库
│   ├── 仓库编辑 / 删除
│   └── 库区与库位
├── 仓库查询
│   ├── SKU 库存视角      （含 Product 汇总 Tab，见 6.1）
│   └── 库存分布详情      （从列表行进入，不单独占一级菜单）
└── 库存流水
    ├── 入库流水          （含期初入库、采购入库）
    ├── 出库占用流水
    ├── 出库扣减流水
    └── 解冻流水
```

左侧二级导航三项：仓库管理、仓库查询、库存流水。库存流水页内四个 Tab 对应四类流水。库存分布详情不是二级菜单，从 SKU（或 Product 下钻到的 SKU）行进入。

## 4. 全局口径与对象

### 4.1 数量口径（全模块共用）

| 名称 | 定义 | 出现位置 |
|---|---|---|
| 实物 `on_hand` | 已锁定 + 未锁定 | 查询各层、流水变更后 |
| 已锁定 `locked` | 出库确认导入后占用、尚未拣货或尚未关单 | 同上 |
| 未锁定 `available` | `on_hand − locked`，可供出库推荐的基础 | 同上 |
| 在途 | 该仓该 SKU、已确认且未关闭采购单的未收数合计；草稿不计 | 仅 SKU / Product 汇总层 |
| 账面 | 实物 + 在途 | 仅 SKU / Product 汇总层；**库位行不展示** |

库位账一行 = 一个库位 × 一个 SKU。汇总是计算得出，不另维护一套仓级账。

### 4.2 空间对象

```text
仓库
 └── 库区（收货区 | 存储区 | 报损区）
      └── 库位 = 仓库 + 库区 + 货架 + 列 + 层（全局唯一）
```

| 对象 | 关键规则 |
|---|---|
| 仓库 | 名称、地址；有库存或未完成采购/入库/出库单不可删 |
| 库区 | 隶属仓库；类型创建后不可改 |
| 库位 | 库存只记在库位；展示编码由五段生成，全局唯一 |
| 已期初 | 只读事实：该仓是否存在类型=期初且已确认的入库单；本模块不提供「做期初」 |

库区用途（本模块展示，写账由入出库遵守）：

| 库区 | 查询是否可见 | 出库推荐 | 一期作业 |
|---|---|---|---|
| 存储区 | 是 | 仅此处，且 `available > 0` | 上架、拣货 |
| 收货区 | 是 | 不参与 | 允许上架暂存 |
| 报损区 | 是（可建档） | 不参与 | 无报损作业、不写库存 |

### 4.3 设计默认（规格未写死，周一逐条确认后去掉「默认」字样）

| 编号 | 默认 |
|---|---|
| Q1 | 库位展示编码系统生成，可复制，参与全局唯一 |
| Q2 | 仓库名称全系统唯一 |
| Q3 | 库区类型创建后不可改 |
| Q4 | 有库存（实物>0 或锁定>0）的库位不可改货架/列/层、不可改所属库区 |
| Q5 | 空库位可删；有库存或被未完成入出库行引用不可删 |
| Q6 | 创建仓库成功后自动生成三个空库区（收货/存储/报损），库位仍手建 |
| Q7 | 一期无按钮级权限 |
| Q8 | 草稿采购单不计入在途 |

## 5. 模块一：仓库管理

维护空间主数据。不展示库存三量编辑框，不发起收货或出库。

### 5.1 仓库列表

**入口：** 库存管理 → 仓库管理。默认落地页。

**目的：** 浏览全部仓库，进入创建、编辑、库区与库位。

**布局：** 页头标题「仓库」+ 主按钮「创建仓库」；下方筛选；再下方表格。

**筛选：**

| 项 | 控件 | 规则 |
|---|---|---|
| 名称 | 输入框 | 模糊匹配，选填 |
| 已期初 | 下拉 | 全部 / 是 / 否 |

**表格列：**

| 列 | 说明 |
|---|---|
| 仓库名称 | 链接，进入该仓「库区与库位」 |
| 地址 | 单行过长省略，悬停全量 |
| 库区数 | 该仓库区个数，创建后应为 3 |
| 库位数 | 该仓库位个数 |
| 已期初 | 是 / 否，只读 |
| 创建时间 | `YYYY-MM-DD HH:mm` |
| 操作 | 编辑、删除、库区与库位 |

**排序：** 默认创建时间倒序。

**空态：** 「还没有仓库」+ 按钮「创建仓库」。无仓库时，仓库查询、库存流水仍可进入，但查询空态提示先建仓。

**无结果态：** 有仓库但筛选无匹配：「没有符合条件的仓库」，保留筛选，不出现创建主按钮替代。

**分页：** 每页 20 条。

**权限与状态：** 删除按钮始终展示；不满足删除条件时点击后弹窗失败原因，不在列表预隐藏（避免运营不知道为何不能删）。

---

### 5.2 创建仓库

**入口：** 列表「创建仓库」。全页或右侧抽屉，原型用全页。

**字段：**

| 字段 | 必填 | 类型 | 约束 |
|---|---|---|---|
| 名称 | 是 | 文本 | 2–50 字，去首尾空格，全系统唯一 |
| 地址 | 是 | 文本 | 1–200 字 |

不提供库区、库位、期初、库存字段。

**按钮：** 取消（回列表，不保存）；提交（校验通过后保存）。

**提交成功：**

1. 生成仓库。
2. 自动创建三个库区：显示名默认「收货区」「存储区」「报损区」，类型分别对应；库位数为 0。
3. 跳转到该仓「库区与库位」，Toast：「仓库已创建，请继续维护库位」。

**校验文案：**

| 条件 | 文案 |
|---|---|
| 名称为空 | 请填写仓库名称 |
| 名称不足 2 字 | 仓库名称至少 2 个字 |
| 名称重名 | 仓库名称已存在 |
| 地址为空 | 请填写仓库地址 |

**取消：** 未改动直接回列表；有改动二次确认「放弃未保存内容？」。

---

### 5.3 仓库编辑 / 删除

#### 5.3.1 编辑

**入口：** 列表行「编辑」。

**可改：** 名称、地址（规则同创建）。已期初、库区数、库位数只读展示，避免在编辑页误改结构。

**提交成功：** 回列表，Toast：「仓库已更新」。名称改后，库位展示编码中的仓段同步更新（见 5.4 编码规则）。

**重名：** 排除自身后仍唯一，否则「仓库名称已存在」。

#### 5.3.2 删除

**入口：** 列表行「删除」。先确认框：「确定删除仓库「{名称}」？删除后不可恢复。」

确认后由系统校验，**全部通过才删除**（级联删除其下空库区；若仍有库位则在库存校验中已失败）。

**拒绝条件（互斥提示，按顺序只报第一条）：**

| 顺序 | 条件 | 文案 |
|---|---|---|
| 1 | 任一库位 `on_hand > 0` 或 `locked > 0` | 该仓库仍有库存，无法删除 |
| 2 | 存在未完成采购单、入库单或出库单 | 该仓库存在未完成的采购/入库/出库单，无法删除 |

未完成单据定义由入库 / 出库提供只读判断，本模块不扫描对方表字段。建议口径（周一与实习生对齐）：

- 采购单：状态不是「已完成」「已关闭」。
- 入库单：尚未确认上架。
- 出库单：状态不是「已发运」「已关闭」（已占用 / 已拣货 / 已打包仍算未完成）。

**成功：** 回列表，该行消失，Toast：「仓库已删除」。

编辑页不放删除，避免在结构页误删；删除只在列表。

---

### 5.4 库区与库位

**入口：** 列表行名称、操作「库区与库位」；创建仓库成功后自动进入。

**目的：** 在指定仓库下维护三类库区及货架-列-层。一期单条新建库位，不做批量生成货架。

**布局：左树右表。**

- 左树：当前仓库为根 → 三个库区节点 → 库区下按货架分组。
- 右表：随选中节点变化。
- 页头：仓库名称、地址（只读）+「编辑仓库」链回编辑页。
- 报损区节点旁固定说明：「一期仅建档，不做出库推荐，不做报损作业。」无「移入报损」等按钮。

**右表随节点：**

| 选中 | 右侧内容 |
|---|---|
| 仓库根 | 三个库区卡片：类型、显示名、库位数 |
| 某一库区 | 该区库位列表 +「新建库位」 |
| 某一货架 | 过滤为该货架下的列-层 |

**库位列表列：** 展示编码、货架、列、层、库区类型、操作（编辑、删除）。本页不展示 SKU 库存数字（库存到仓库查询看）。

**新建库位：**

| 字段 | 必填 | 规则 |
|---|---|---|
| 库区 | 是 | 默认当前树节点所属库区，可改为本仓另一库区 |
| 货架 | 是 | 1–20 字，去首尾空格 |
| 列 | 是 | 1–20 字 |
| 层 | 是 | 1–20 字 |
| 展示编码 | 只读 | 提交前预览，提交后生成 |

展示编码默认：`{仓短码}-{区类型码}-{货架}-{列}-{层}`。

- 仓短码：创建仓库时生成，如 `W001`，不随名称改而改（避免改名导致历史流水编码对不上）。名称仍可改。
- 区类型码：收货区 `RCV`，存储区 `STO`，报损区 `DMG`。

全局唯一键：仓库 + 库区 + 货架 + 列 + 层。展示编码亦唯一。重复时：「该库位已存在（{展示编码}）」。

**编辑库位：** 无库存且未被未完成单据行引用时，可改货架/列/层（编码重算，仍校验唯一）。有库存或被引用时字段只读，提示：「有库存或被未完成单据引用的库位不可更改货架/列/层」。不可改所属库区、不可改库区类型。

**删除库位：**

| 条件 | 处理 |
|---|---|
| 实物=0 且锁定=0，且无未完成入出库行引用 | 二次确认后删除 |
| 有库存 | 「该库位仍有库存，无法删除」 |
| 被未完成单据引用 | 「该库位存在未完成的入库/出库行，无法删除」 |

**库区：** 一期不提供删除库区、不提供新增第四类库区、不提供改类型。显示名可改（1–20 字），类型徽章不变。

**空态：** 某区无库位：「该库区还没有库位」+「新建库位」。报损区同样允许建位，仅无作业按钮。

## 6. 模块二：仓库查询

只读。数字来自库位账 + 采购未收（在途）。本模块不写库存。筛选含仓库、库区、SKU 编码/名称、仅显示有货（规格）。

拍板要求 Product / SKU 两种视角。本模块页面按你确认的结构拆成「SKU 库存视角」与「库存分布详情」；Product 作为 SKU 库存视角页内 Tab，不单开一级模块。

贯穿示意数据（原型与用例共用）：

```text
SKU: 20000MA Large Capacity Mini Comes with Four wire Power Bank-黑色
实物 100    已锁定 2    未锁定 98
```

### 6.1 SKU 库存视角

**入口：** 库存管理 → 仓库查询。默认 Tab「SKU」。

**目的：** 一行一个 SKU（或 Product），看汇总三量及账面，再进入分布。

**页头 Tab：** `SKU` | `Product`。

#### 6.1.1 筛选（两 Tab 共用）

| 项 | 控件 | 规则 |
|---|---|---|
| 仓库 | 下拉，含「全部」 | 默认全部 |
| 库区 | 下拉，含「全部」及类型名 | 选「全部仓库」时库区为全部或按类型过滤（收货/存储/报损）；选中具体仓后列出该仓三个区 |
| 关键词 | 输入 | SKU Tab：匹配 SKU 编码或名称；Product Tab：匹配 Product 编码或名称 |
| 仅显示有货 | 开关 | 默认关。打开后：实物>0 **或** 已锁定>0（避免仅占用、实物暂未扣减前被滤掉；在途单独有货但实物与锁定均为 0 时，打开开关不展示——在途不是仓内实物） |

筛库区时，汇总三量 **只统计落入该库区的库位**；在途、账面：

- 未选具体库区：在途按仓+SKU 计，账面=该范围实物+在途。
- 选了库区：在途、账面列显示「—」，表头 Tooltip：「在途按采购未收到仓+SKU，不拆到库区」。

#### 6.1.2 SKU Tab 表格

一行一个 SKU。

| 列 | 说明 |
|---|---|
| SKU 编码 | 来自商品副本 |
| SKU 名称 | |
| Product | 所属 Product 名称，只读 |
| 实物 | 当前筛选范围内库位 on_hand 之和 |
| 已锁定 | locked 之和 |
| 未锁定 | available 之和 |
| 在途 | 见 4.1；筛到库区时为 — |
| 账面 | 实物+在途；筛到库区时为 — |
| 操作 | 「分布」进入库存分布详情 |

**数字对齐：** 未锁定必须等于 实物 − 已锁定。若不等，视为写账缺陷，本页不提供「修正」按钮。

**行点击：** 点击行或「分布」进入 6.2，带入该 SKU + 当前仓库/库区筛选。

**空态：**

| 情况 | 文案 |
|---|---|
| 系统尚无仓库 | 请先在仓库管理中创建仓库 |
| 有仓、无任何库位库存且无在途 | 暂无库存 |
| 筛选无匹配 | 没有符合条件的库存 |

**排序：** 默认实物倒序。分页 20。

#### 6.1.3 Product Tab

一行一个 Product，数量为其下 SKU 在当前筛选范围内的合计。列：Product 编码、名称、SKU 数、实物、已锁定、未锁定、在途、账面。

点击 Product 行：展开或进入该 Product 下 SKU 子表（列同 SKU Tab）。再点某一 SKU 的「分布」进入 6.2。不允许从 Product 行直接跳到库位（必须落到 SKU，因为库位账按 SKU 记）。

电商下架的 SKU：副本仍展示；一期不对下架做额外策略（规格：已有单据可完成；新单预检告警不在一期做复杂策略）。本查询照常显示账上数量。

### 6.2 库存分布详情

**入口：** 仅从 6.1 的 SKU「分布」进入。不出现在左侧二级导航。

**页头：** SKU 编码与名称；返回「SKU 库存视角」。汇总条：当前筛选下的实物 / 已锁定 / 未锁定；未按库区筛选时另显示在途、账面。

**目的：** 把该 SKU 拆到仓库 → 库区 → 货架-列-层。规格下钻层级：仓库 / 库区 / 货架-列-层。

**布局：** 三级，默认展开到库区，库位表在库区内。

**第一层 · 按仓库**

| 列 | 说明 |
|---|---|
| 仓库 | |
| 实物 / 已锁定 / 未锁定 | 该 SKU 在该仓全部库位合计 |
| 在途 | 该仓该 SKU 采购未收；与库区无关 |
| 账面 | 该仓实物+在途 |

若 6.1 已筛某一仓库，本层只显示该仓一行。

**第二层 · 按库区（仓下展开）**

| 列 | 说明 |
|---|---|
| 库区名称 | 带类型徽章：收货区 / 存储区 / 报损区 |
| 实物 / 已锁定 / 未锁定 | |
| 说明 | 收货区行固定文案：「不参与出库推荐」。报损区行：「一期不写入库存」。存储区无额外文案 |

库区层 **不展示在途、账面**。

若 6.1 已筛某一库区，只展开该区。

**第三层 · 库位（货架-列-层）**

| 列 | 说明 |
|---|---|
| 展示编码 | |
| 货架 / 列 / 层 | |
| 实物 | 该库位该 SKU 的 on_hand |
| 已锁定 | locked |
| 未锁定 | available |

库位行不展示在途、账面。未锁定 = 实物 − 已锁定。

**仅有货：** 若 6.1 打开了「仅显示有货」，分布页库位默认隐藏三量均为 0 的行；库区/仓库若展开后无行则不展示该节点。

**空态：** 该 SKU 在筛选范围内无库位账：「该 SKU 在当前范围内没有库位库存」。若仅有在途：汇总条在途>0，分布库位空态补充：「在途未收货，尚未落到库位」。

**不提供：** 改库位、冻结、上架、推荐路径、跳转出发货。可提供「查看该库位流水」链到库存流水并带上 SKU+库位筛选（可选，一期建议做，减少对账成本）。

## 7. 模块三：库存流水

只读，禁止手工新增/改账。一期界面只开放规格中的类型；盘盈、盘亏、报损、移库仅对象预留，Tab 与筛选项均不出现。

**入口：** 库存管理 → 库存流水。页内四个 Tab，对应下列四节；共用筛选区，切换 Tab 时保留仓库/SKU/时间等，类型随 Tab 固定。

**共用筛选：**

| 项 | 规则 |
|---|---|
| 时间 | 日期范围，默认近 7 天（含今天） |
| 仓库 | 全部 / 指定 |
| 库位 | 展示编码模糊搜，选填 |
| SKU | 编码或名称，选填 |
| 关联单号 | 精确或模糊，选填 |
| 操作人 | 选填 |

**共用列：**

| 列 | 说明 |
|---|---|
| 时间 | 写账时间 |
| 仓库 | |
| 库位 | 展示编码（含货架-列-层） |
| SKU | 编码 + 名称 |
| 数量 | 本行变动件数，正数；方向用类型解释，不另用正负号以免和三量混淆 |
| 变更后实物 | 本库位该 SKU 写账后 on_hand |
| 变更后已锁定 | 写账后 locked |
| 变更后未锁定 | 写账后 available |
| 类型 | 见各节 |
| 关联单号 | 入库单号或出库单号 |
| 操作人 | |

一期关联单号只展示文本，不强制跳转入库/出库详情（对方页面未交付时避免死链）。分页 20，默认时间倒序。

**空态：** 「所选条件下没有流水」。无「创建流水」按钮。

**打包 / 发运：** 不写本模块任何 Tab。验收时发运前后流水条数与三量不变。

以下四节描述各 Tab 的类型、写账时点（供对照，写入由入出库执行）和阅读方式。

---

### 7.1 入库流水

**Tab 名：** 入库。  
**包含类型：** `期初入库`、`采购入库`。  
**Tab 内子筛：** 全部 / 期初入库 / 采购入库。

**何时出现：** 入库单确认上架成功后，按库位×SKU 一行（或多行）。同一采购单分次收、多张入库单，每次确认各写一批。

**三量变化：** 实物↑、未锁定↑、已锁定不变。数量 = 本行实收并上架件数。

**关联单号：** 入库单号。采购入库可在名称或次要信息中展示来源采购单号（只读）；期初无采购单号。

**阅读要点：**

- 期初：每仓仅一次成功确认；本 Tab 按仓筛选时可核对是否已有期初入库记录（与仓库列表「已期初」一致）。
- 采购：可与入库模块已收/未收对照；本页不展示采购未收，未收看在途（仓库查询）。

**示例（原型）：** 存储区某库位上架 100，变更后实物 100、锁定 0、未锁定 100，类型采购入库。

---

### 7.2 出库占用流水

**Tab 名：** 出库占用。  
**类型：** `出库占用`（规格用语；与「冻结」「已占用」同一事件）。

**何时出现：** 出库预检通过且用户确认导入之后。预检阶段 **零流水**。确认时按确认库位逐行冻结；一行一个库位（出库侧拆行）。

**三量变化：** 未锁定↓、已锁定↑、实物不变。数量 = 本行冻结件数。

**关联单号：** 出库单号。parcel 不作为本表必列；需要时可放在单号旁次要文字，一期可不做。

**阅读要点：** 占用后仓库查询中该 SKU 未锁定减少、锁定增加、实物不变。若确认时可用已被其他单占用，出库应拒绝冻结且 **本 Tab 不出现半截流水**（整单失败）。

**示例：** 冻结 2，变更后实物 100、锁定 2、未锁定 98。

---

### 7.3 出库扣减流水

**Tab 名：** 出库扣减。  
**类型：** `出库扣减`。

**何时出现：** 拣货确认（按行，确认库位上 locked 与 on_hand 同减）。打包、发运不写本 Tab。

**三量变化：** 已锁定↓、实物↓、未锁定不变。数量 = 本行拣货件数。

**关联单号：** 出库单号。

**阅读要点：** 扣减后查询中实物与锁定同时下降。发运后不应再多一条扣减。

**示例：** 扣减 2，变更后实物 98、锁定 0、未锁定 98。

---

### 7.4 解冻流水

**Tab 名：** 解冻。  
**类型：** `取消解冻`（规格类型名；Tab 对外可用「解冻」）。

**何时出现：** 关闭已占用出库单，按行解冻。已拣货后是否允许关单由出库模块定义；本模块只展示对方写出的解冻流水。规格明确：关闭已占用出库单 → 已锁定↓、未锁定↑，写解冻流水。

**三量变化：** 已锁定↓、未锁定↑、实物不变。数量 = 本行解冻件数。

**关联单号：** 出库单号。

**阅读要点：** 解冻后查询恢复为占用前的未锁定。不得把解冻写成入库流水。

**示例：** 解冻 2，变更后实物 100、锁定 0、未锁定 100。

---

## 8. 跨模块契约（发给入库 / 出库实习生）

本模块不实现入出库，但查询与流水数字必须按下表对上。对方 PRD 不得另造口径。

### 8.1 库区写入

| 动作 | 允许库区 |
|---|---|
| 入库实际上架 | 收货区、存储区 |
| 入库历史建议库位 | 仅存储区，该 SKU 本仓最近一次成功上架 |
| 出库推荐与确认冻结 | 仅存储区且 available>0 |
| 报损区 | 任何作业都不得写入库存 |

### 8.2 写账与流水类型

| 事件 | 实物 | 锁定 | 未锁定 | 流水 Tab / 类型 |
|---|---|---|---|---|
| 期初或采购确认上架 | ↑ | — | ↑ | 入库 / 期初入库或采购入库 |
| 出库确认导入 | — | ↑ | ↓ | 出库占用 / 出库占用 |
| 拣货确认 | ↓ | ↓ | — | 出库扣减 / 出库扣减 |
| 关闭已占用出库单 | — | ↓ | ↑ | 解冻 / 取消解冻 |
| 打包 / 发运 | 不变 | 不变 | 不变 | 不写流水 |

出库、日常入库 Excel：预检全过才允许确认；失败整单不写库存、不写流水。

### 8.3 本模块提供给对方（实现阶段，本周不写代码）

- 仓库 / 库区 / 库位主数据。
- 出库推荐数据源：指定仓 + SKU + 类型=存储区 + available>0，按 available 从大到小。拆行由出库做。
- 删仓前 `可删除(仓库)`：无库存且对方返回无未完成单据。
- 在途读取：已确认未关闭采购行未收数合计（草稿不计）。

### 8.4 商品副本

查询与流水展示名称时读本地副本。本模块不因电商不可达而创建商品。预检失败规则在入出库。

## 9. 验收用例

### 9.1 仓库管理（可独立验）

1. 创建仓库（名称、地址）后出现在列表，并自动具备三类库区。
2. 在存储区新建到货架-列-层；重复五段被拦截并提示已存在编码。
3. 报损区可进入、可建空库位，无报损作业按钮。
4. 无库存且无未完成单据时可删除仓库；有库存、有未完成单据时分别出现第 5.3.2 节文案。
5. 编辑仓库名称/地址成功；名称与另一仓冲突失败。
6. 有库存库位不可改货架/列/层、不可删除。

### 9.2 仓库查询（页面独立验，数字联调验）

7. SKU Tab 一行一 SKU，列含实物/锁定/未锁定；未筛库区时含在途、账面。
8. Product Tab 按 Product 汇总，必须点到 SKU 才能进分布。
9. 分布详情可下钻仓库 → 库区 → 货架-列-层；库位行无在途、账面。
10. 收货区库存在分布中可见，并标明不参与出库推荐。
11. 「仅显示有货」按 6.1.1 过滤。无仓、无库存、筛选无结果三种空态可区分。
12. 示意口径：实物 100、锁定 2、未锁定 98。

### 9.3 库存流水

13. 四个 Tab 均可进入；无盘盈/盘亏/报损/移库。
14. 入库 Tab 可区分期初与采购；占用/扣减/解冻分属后三个 Tab。
15. 每条流水含时间、仓库、库位、SKU、数量、变更后三量、类型、关联单号、操作人。
16. 联调：上架只进入库流水；确认出库只进占用；拣货只进扣减；关单只进解冻；发运不增流水且三量不变。

### 9.4 全模块

17. 导航无盘库、退货、回写电商、采购一级菜单。
18. 本模块任何页面不能直接改 on_hand / locked。

## 10. 非功能（极简）

单仓库位规模按数百计，库区与库位树需可滚动浏览。不做拣货路径优化。流水默认近 7 天，避免首屏拉全量。

## 11. 周一评审时禁止重开的结论

系统独立、WMS 不建品、不回写可售、日常入库必须采购单、每仓一次期初、出库预检不写库、确认后冻结、拣货扣减、打包发运只改状态、推荐只走存储区、报损区只建档、无部分成功导入。

评审只确认第 4.3 节 Q1–Q8 设计默认，以及未完成单据状态名与入库/出库 PRD 对齐。确认后本文升 v1.0，默认写进正文，去掉「默认」字样。未获批准前不写 WMS 业务代码。
