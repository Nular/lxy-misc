# KickBazar ToC 网页端 — Brainstorming 梳理文档

> **产品**：KickBazar（kickbazar.com）  
> **文档版本**：v0.2  
> **目标市场**：孟加拉国（Bangladesh）  
> **目标**：网页端功能与 App 保持一致，交互与页面设计参考 SHEIN  
> **方法**：Brainstorming（发散 → 归类 → 收敛）  
> **App 参考**：kickbazar.com（现有移动端 App）

---

## 一、项目背景与市场设定

### 1.1 核心问题

| 维度 | 描述 |
|------|------|
| **现状** | KickBazar 目前仅有移动端 App，服务孟加拉用户，缺少网页端触达 |
| **目标** | 开发 ToC 网页端，Page List 与 App 对齐，覆盖完整购物闭环 |
| **参考** | 交互与视觉参考 SHEIN 网页端；业务逻辑以 App 为准 |
| **域名** | kickbazar.com |

### 1.2 孟加拉市场特性（本地化 Brainstorming）

| 维度 | 要点 | 网页端落地 |
|------|------|-----------|
| **语言** | 孟加拉语（বাংলা）+ 英语双语 | 语言选择页；默认跟随浏览器/上次选择；RTL 不需要 |
| **货币** | BDT（৳ 塔卡） | 全站统一 BDT 展示，千分位格式 |
| **支付** | 移动端钱包普及（bKash、Nagad、Rocket 等） | 结算页支付方式与 App 一致；Web 需考虑跳转/回调 |
| **地址** | Division → District → Upazila/Thana → 详细地址 | 四级联动选择器；手机号 +880 格式校验 |
| **物流** | 本地配送时效、COD（货到付款）可能性 | 商品详情/结算页前置配送说明 |
| **网络** | 部分用户网络较慢 | 图片懒加载、骨架屏、轻量首屏 |
| **信任** | 跨境/本对本电商需强化售后政策可见性 | 底栏常驻：配送/退换/联系我们 |
| **合规** | 隐私 & Cookie 政策 | 首访 Cookie 同意条；设置页可查看政策 |

### 1.3 用户画像（孟加拉）

| Persona | 特征 | 核心诉求 | 典型路径 |
|---------|------|---------|---------|
| **P1 达卡都市年轻用户** | 18–30 岁，智能手机重度 | 潮流单品、低价、快速到货 | 首页 → 潮流专题 → 下单 |
| **P2 价格敏感用户** | 关注折扣与包邮 | 券、满减、比价 | 搜索 → 筛选低价 → 购物车 |
| **P3 复购用户** | 有历史订单 | 快速复购、地址记忆 | 个人中心 → 再次购买 |
| **P4 英语/孟语切换用户** | 双语使用 | 看得懂、操作顺 | 语言选择页 → 全站文案切换 |

### 1.4 设计原则（SHEIN 参考 + KickBazar 适配）

| 原则 | SHEIN 特征 | KickBazar Web 落地 |
|------|-----------|-------------------|
| 高密度货架 | 首屏即商品 | 首页/分类/搜索均瀑布流或网格 |
| 短路径转化 | 加购 → 结算 ≤ 3 步 | 全局购物车角标 + Sticky 结算栏 |
| 搜索强引导 | 热搜 + 联想 + 多维筛选 | 搜索起始页承载发现能力 |
| 筛选组件化 | Featured / Filter / Sort 分层 | 搜索结果页拆为子视图（与 App 一致） |
| 登录后置 | 浏览无需登录 | 结算/订单/个人中心触发登录 |
| 政策透明 | 底栏法律与帮助链接 | 配送/退换/条款/隐私独立页 |

## 三、分模块 Brainstorming 详述

---

### 模块 A：首页

#### A1. 欢迎页 🚫 App 特有

| 项 | 说明 |
|----|------|
| **网页策略** | 不做独立欢迎页；启动体验由「首页-服务介绍」承接 |
| **替代方案** | 首次访问 Cookie 条 + 可选新客引导弹层 |

#### A2. 首页-服务介绍

**定位**：新客/首访用户的服务价值传达层，可覆盖在首页之上或作为首页第一屏模块。

| 发散点 | 类型 | 优先级 | Web 实现建议 |
|--------|------|--------|-------------|
| 全球好物/本地配送卖点 | 必备 | P0 | 首屏 Banner 文案，3–4 个 Icon 卖点 |
| 免邮门槛说明 | 运营 | P0 | 与孟加拉配送政策联动 |
| 支付方式图标（bKash 等） | 信任 | P0 | 横向滚动展示 |
| 跳过/关闭按钮 | 体验 | P0 | 关闭后写入 localStorage，不再展示 |
| 引导至分类/专题 | 转化 | P1 | CTA：「开始购物」 |

**SHEIN 参考**：类似首访时的促销条 + 信任背书区，不做全屏阻断。

#### A3. 首页

| 发散点 | 类型 | 优先级 |
|--------|------|--------|
| 顶部搜索框（跳转搜索起始页） | 必备 | P0 |
| 轮播 Banner（运营配置，可链专题页） | 必备 | P0 |
| 一级分类入口（宫格/横滑） | 必备 | P0 |
| 专题入口：品牌馆/国家馆/精选/潮流 | 运营 | P0 |
| 商品推荐流（瀑布流/网格） | 必备 | P0 |
| 商品推荐组件（可复用） | 必备 | P0 |
| 底栏导航：Home / Categories / Cart / Account | 必备 | P0 |
| 多语言切换入口 | 必备 | P0 |

**页面结构**

```
[顶栏：Logo | 搜索 | 语言 | 购物车 | 账户]
[服务介绍条（首访，可关闭）]
[Banner 轮播]
[分类宫格]
[专题入口横滑：品牌馆 | 国家馆 | 精选 | 潮流]
[推荐商品标题 + Tab]
[商品推荐组件 — 无限滚动]
[底栏：政策链接 + 社媒]
[Mobile 底 Tab：Home | Categories | Cart | Account]
```

**B2.4 搜索结果页-排序**

**SHEIN 参考**：筛选左侧固定 + 顶部排序下拉；Featured 以顶部 Tab 呈现。

## 五、关键用户旅程

### 旅程 1：新客首购（孟加拉）

```
广告/社媒 → 首页（服务介绍关闭）→ 潮流专题
  → 商品详情 → 规格选择器 → 加购 → 购物车
  → 结算 → 登录/注册 → 新增地址（Division/District/Upazila）
  → 选择 bKash 等支付 → 订单提交结果页
```

### 旅程 2：搜索购买

```
搜索起始页 → 输入关键词 → 结果页
  → Featured 筛选 / 过滤 / 排序 → 商品详情 → 立即购买 → 结算
```

### 旅程 3：老客复购

```
个人中心 → 订单列表 → 再次购买 → 购物车 → 结算（地址已有）
```
