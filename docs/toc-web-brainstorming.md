# 跨境电商平台 ToC 网页端 — Brainstorming 梳理文档

> **文档版本**：v0.1（Brainstorming 初稿）  
> **目标**：在功能与 App 保持一致的前提下，梳理网页端 ToC 模块，交互与页面设计参考 SHEIN  
> **范围**：导购与发现、交易转化、订单与履约、个人中心、用户认证  
> **方法**：Brainstorming（发散 → 归类 → 收敛）

---

## 一、Brainstorming 会话设定

### 1.1 核心问题（Problem Statement）

| 维度 | 描述 |
|------|------|
| **现状** | 公司仅有移动端 App，缺少网页端触达渠道 |
| **目标** | 开发 ToC 网页端，功能与 App 对齐，覆盖完整购物闭环 |
| **参考** | 交互与页面设计参考 SHEIN 网页端（简洁、高密度商品展示、强转化导向） |
| **约束** | 首期仅梳理 ToC 模块，不涉及 ToB / 运营后台 |

### 1.2 设计原则（从 SHEIN 提炼）

| 原则 | 说明 | 网页端落地 |
|------|------|-----------|
| **视觉密度高** | 首屏即见商品，减少无效留白 | 瀑布流 / 多列网格，PC 端 4–6 列 |
| **路径极短** | 浏览 → 加购 → 结算 ≤ 3 步 | 全局悬浮购物车、快捷加购弹层 |
| **强导购** | 首页即货架，分类即频道 | 首页模块化运营位 + 分类 Tab 导航 |
| **响应式优先** | 一套代码适配 PC / Pad / Mobile Web | 断点：≥1200 / 768–1199 / <768 |
| **登录轻量** | 浏览无需登录，结算再引导 | 游客可浏览、加购，结算时登录/注册 |
| **跨境友好** | 多币种、多语言、国际物流可见 | 顶部全局切换器，物流时效前置展示 |

### 1.3 用户画像（Persona 速记）

| Persona | 特征 | 核心诉求 | 网页端场景 |
|---------|------|---------|-----------|
| **P1 价格敏感型** | 18–35 岁，追求性价比 | 快速比价、优惠券、限时折扣 | 搜索 + 分类筛选 + 活动页 |
| **P2 种草跟随型** | 社交媒体引流 | 同款、店铺、榜单 | 首页推荐 + 店铺页 |
| **P3 复购忠诚型** | 有历史订单 | 快速复购、地址记忆 | 个人中心 + 订单列表 |
| **P4 跨境新客** | 首次购买 | 信任感、物流时效、退换政策 | 商品详情 + 物流说明 |

#### A6. 空状态（全局）

| 场景 | 文案方向 | 行动按钮 | 配图 |
|------|---------|---------|------|
| 搜索无结果 | 「未找到相关商品，换个关键词试试」 | 返回首页 / 查看推荐 | 空盒子插画 |
| 购物车为空 | 「购物车是空的，去逛逛吧」 | 去首页 / 去分类 | 空购物车插画 |
| 订单为空 | 「还没有订单哦」 | 去购物 | 空订单插画 |
| 收藏为空 | 「还没有收藏的商品」 | 去逛逛 | 空爱心插画 |
| 地址为空 | 「请添加收货地址」 | 新增地址 | — |
| 优惠券为空 | 「暂无可用优惠券」 | 去领券中心 | — |
| 网络错误 | 「网络开小差了」 | 重试 | 断网插画 |
| 页面 404 | 「页面不存在」 | 返回首页 | — |
| 商品已下架 | 「该商品已下架」 | 查看相似商品 | — |
| 地区不可售 | 「该商品暂不支持配送到您的地区」 | 更换地址 | — |

**设计原则**

- 空状态不是死胡同，必须提供下一步行动
- 视觉风格与 SHEIN 一致：轻量插画 + 简短文案
- 能展示推荐则展示（搜索无结果、商品下架）

## 五、关键用户旅程（User Journey）

### 旅程 1：新客首购

```
社媒广告 / SEO → 首页 → 浏览推荐 → 商品详情
  → 选 SKU → 加购 → 继续逛 → 购物车 → 结算
  → 登录弹层（注册） → 填地址 → 选支付 → 支付成功
  → 订单详情
```

### 旅程 2：老客复购

```
直接访问 → 搜索关键词 → 筛选 → 商品详情
  → 立即购买 → 结算（地址已有） → 支付 → 完成
```

### 旅程 3：订单追踪

```
个人中心 → 待收货 → 订单详情 → 物流详情
  → 确认收货 → 评价
```

## 六、网页端 vs App 差异汇总

| 维度 | App | Web（建议） |
|------|-----|------------|

| 筛选 | 底部弹层 | PC 左侧固定栏 |

| 游客模式 | 有限 | 本地购物车，结算时登录 |
| 推送 | App Push | 邮件 / 浏览器通知（可选） |
