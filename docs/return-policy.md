# KickBazar | 退货退款政策

**最后更新日期：2026年09月24日**

本《退货退款政策》说明用户通过 KickBazar 购买商品后，申请退货、换货、退款、退货物流、质检以及售后处理的相关规则。

当您在 KickBazar 提交订单，即表示您同意本退货退款政策中与售后服务相关的条款。本政策应与 KickBazar《配送政策》及其他适用平台规则一并阅读。

---

## 1. 政策适用范围

本政策适用于用户通过 KickBazar 网站或移动应用购买、并已完成配送签收（或按平台规则视为已送达）的商品。

实际可退货、可退款范围可能受到以下因素影响：

- 商品类型及品类；
- 商品详情页标注的退货说明；
- 商家类型（平台自营、本地商家、跨境供应商等）；
- 是否为孟加拉本地商品或跨境商品；
- 商品使用、穿着、洗涤、开封或损坏情况；
- 适用法律法规及消费者保护规定；
- 其他实际运营条件。

如果某件商品因法律、卫生、安全、定制属性或商品页明确标注等原因不符合退货条件，KickBazar 可能无法受理该商品的退货申请，但用户针对错误商品、损坏商品、质量问题商品或其他不符合约定商品依法享有的权利不受影响。

## 2. 退货期限

在符合本政策及商品页说明的前提下，用户可在以下期限内申请退货退款：

### 2.1 一般退货期限

对于大多数符合退货条件的全新商品，用户可在商品**签收之日起 15 天内**申请退货。

### 2.2 特殊品类期限

| 情形 | 建议申请期限 |
| --- | --- |
| 普通可退货商品（服装、鞋包、家居等） | 签收后 15 天内 |
| 部分电子产品 | 签收后 7 天、15 天或商品页另行标明的期限 |
| 送达时已损坏、明显质量缺陷或错发的商品 | 签收后尽快申请，建议不超过 7 天；严重质量问题最长可参考 90 天内联系客服 |
| 符合条件的生鲜、易腐或短保商品（如平台销售） | 签收后 24–72 小时内 |

商品页面、结算页面或订单页面显示的退货说明通常优先适用。若商品页标注“不可退货”或更短/更长的退货窗口，以商品页及本政策中更具体的说明为准，但不得排除适用法律赋予消费者的强制性权利。

### 2.3 申请与寄回时限

- 用户须在退货期限内提交退货/退款申请；
- 若商品需要寄回，退货包裹须在**提交退货申请后 14 天内**交付物流服务商寄出（以物流揽收或邮戳时间为准）；
- 逾期未寄出的，退货流程可能被终止，相关申请可能被关闭。

退货窗口关闭后，用户通常无法再发起常规退货，但仍可就法定保修、隐藏缺陷或重大质量问题联系 KickBazar 客服。

## 3. 可退货与不可退货商品

### 3.1 可退货商品的基本要求

除非另有说明，可退货商品一般须同时满足：

- 处于全新、未使用、未穿着、未洗涤、未损坏、未改动状态；
- 保留原始吊牌、标签、卫生贴纸（如适用）；
- 保留原包装、说明书、配件、赠品及条形码（如适用）；
- 与退货申请中选择的商品、规格、数量一致；
- 未被商品页或商家明确标注为不可退货。

### 3.2 常见品类退货要求

**服装、婚纱、套装及其他服饰**  
须全新、未穿、未洗、未改，并保留原始标签及完整卫生贴纸（如适用）。

**鞋类、箱包、行李**  
须全新、未穿着或仅在柔软干净表面短时试穿，未损坏，并附原厂包装盒及全部配件（鞋扣、鞋带、防尘袋等）。

**假发及类似商品**  
须全新、未穿戴、未洗涤、未漂白、未剪裁、未改动，并附原始标签。

**电子产品（手机、平板、笔记本电脑、投影仪等）**  
须未激活或符合商品页退货条件；退回前请清除全部个人信息和账户数据，并连同说明书、配件及随附赠品一并退回原包装。缺少零件或无法再销售的，可能无法全额退款。

**家具及大件商品**  
须未使用、未损坏，并保留原包装及全部配件、说明书和零件。

**套装商品**  
套装内全部组件一般须一并退回；仅退回部分组件可能导致退款金额扣减或申请被拒绝。

### 3.3 通常不可退货的商品

以下商品通常不支持因“不想要了”“尺码不合适”“个人喜好改变”等原因退货：

- 内衣、内裤、连体衣、泳装等贴身衣物（因质量问题、错发或损坏除外）；
- 已开封的化妆品、护肤品、个人护理用品；
- 珠宝首饰、美妆部分品类（以商品页为准）；
- 食品、生鲜、杂货（送达损坏或缺陷除外）；
- 药品、部分健康护理用品；
- 定制商品、个性化刻字/印制商品；
- 免费赠品（是否可退取决于订单规则及付款时商品状态）；
- 活动及派对用品、部分 DIY 用品、部分宠物用品（以商品页为准）；
- 密封包装已被打开且影响二次销售的商品；
- 商品页明确标注“不支持退货”的商品；
- 法律法规或卫生安全要求禁止退回的商品。

卖家或商品页可能对特定商品作出更严格的退货限制，但仍须遵守本政策及适用法律。请以商品详情页说明为准。

## 4. 如何申请退货/退款

您可以按照以下步骤申请退货或退款：

1. 登录您的 KickBazar 账户（网站或 App）。如无法登录，可通过订单确认邮件/短信中的订单入口进入售后流程。
2. 进入“我的订单”或“您的订单”，找到相关订单。
3. 点击“退货/退款”或类似按钮，选择需要售后的商品及退货/退款原因。
4. 根据所选原因，按提示补充说明，并在需要时上传照片、开箱视频或其他证明材料。
5. 确认该商品是否需要寄回：
   - **无需寄回**：按提示选择退款方式并提交；质检或审核通过后处理退款；
   - **需要寄回**：选择退货方式与退款方式并提交；系统将提供退货指引、退货标签、退货码或自寄说明。
6. 如需寄回，请按第 6 节要求包装并寄出退货包裹。
7. 您可在订单详情、退货详情页，或通过短信 / Email / App 推送查看退货与退款进度。

### 注意事项

- 同一订单中的多件可退货商品，建议尽量合并一次寄回，以减少费用与物流延误；
- 不同订单的商品，仅在平台明确支持“合并退货”时，才可放入同一退货包裹；
- 在部分情形下（如低价值商品、明显物流损坏且已充分举证、平台认定无需退回等），KickBazar 可自行决定是否在不要求寄回商品的情况下直接退款；
- 第三方卖家订单可能需卖家先审核退货申请；超时未处理的，您可联系 KickBazar 客服协助处理。

## 5. 退货方式与退货运费

KickBazar 可能根据收货地区、商品类型、包裹重量尺寸及物流覆盖情况，提供以下一种或多种退货方式：

| 退货方式 | 说明 | 费用规则（一般情况） |
| --- | --- | --- |
| 平台退货标签 / 上门取件 | 提交申请后生成退货标签、取件码或预约取件 | 每个订单在退货期限内的**首次**合格退货，通常免退货运费（存在例外） |
| 指定网点投递 | 将贴好标签或出示退货码的包裹送至指定快递网点 | 首次合格退货通常免费；二次及以后可能扣减退货运费 |
| 用户自行寄回 | 超大、超重、偏远地区或承运商限制时适用 | 用户先垫付运费并保留凭证；商品通过质检后，可按规则申请运费补偿（可能以 KickBazar 余额/抵用金形式退回） |

### 5.1 免费退货

在退货期限内，对于每个订单，**首次**退回一件或多件可退货商品，通常可享受免退货运费。但存在例外，例如：

- 超大件、超重件需自寄的商品；
- 偏远地区或物流服务商未覆盖上门取件的区域；
- 非因 KickBazar 或商家过错、且平台规则明确需用户承担退货运费的情形；
- 同一订单的第二次及后续退货。

### 5.2 二次及后续退货

如果同一订单已完成过退货，且退货窗口尚未关闭，用户仍可对剩余可退货商品再次申请退货。为降低费用与环境影响，我们建议一次性寄回。

对同一订单的第二次及后续退货，平台可能：

- 仍提供退货标签；但
- 从退款金额中扣除合理退货运费及依法应计的税费（具体金额以申请页面展示为准）。

### 5.3 因平台或商家原因导致的退货

因以下原因退货的，用户通常无需承担退货运费，且符合条件的原配送费、进口税费等可按规则退还：

- 收到错误商品；
- 商品存在质量问题或重大描述不符；
- 商品破损、缺件、少件；
- 物流导致的明显损坏；
- 其他经核实属于 KickBazar 或商家责任的情形。

### 5.4 重要提醒

- **请勿**将退货包裹寄回原包裹外包装上的寄件地址，该地址通常不是有效退货地址，可能导致无法退款或严重延误；
- 请仅使用退货申请中提供的退货标签、退货码或退货地址；
- 如使用原运输包装退货，请移除或覆盖原物流面单，避免包裹被误寄回给您。

## 6. 退货包装与寄回要求

寄出退货前，请确保：

1. 将所有拟退回商品放入同一退货包裹（除非平台要求分包裹）；
2. 保留每件商品的原始条形码、吊牌及配件；如条形码脱落，请用透明袋单独包装无条形码商品后再放入包裹；
3. 打印或保存平台提供的退货标签 / 二维码 / 取件码，并按指引粘贴或出示；
4. 妥善包装，避免退回运输途中二次损坏；
5. 不要误放入不打算退回的个人物品或其他订单商品。

仓库收到商品后将进行质检。质检通过后处理退款。若长时间未收到退款，请联系 KickBazar 客服。

如误寄非退货商品，请尽快联系客服。我们会尽力协助查找，但无法保证一定找回，也无法承诺为误寄商品提供保管、退回、退款或赔偿。

## 7. 修改、取消退货申请

### 7.1 修改退货申请

在退货包裹尚未寄出、且申请仍处于可修改状态时，您通常可以：

进入“我的订单” → “退货/退款记录” → “详情” → “修改退货商品”，新增或删除商品并重新提交。

商品已揽收或进入质检后，可能无法再修改。

### 7.2 取消退货申请

在物流尚未取件或平台允许取消的阶段，您可以：

进入“我的订单” → “退货/退款记录” → “详情” → “取消申请”。

已寄出、已入库或已退款的申请，通常无法直接取消。若您已寄出但仍希望终止，请立即联系客服，能否拦截取决于物流进度，不保证成功。

### 7.3 查找退货标签 / 二维码

进入“我的订单” → “退货”或“退货/退款记录” → “详情” → “打印/保存退货标签”或“查看退货码”。

## 8. 部分退货与部分退款

一个订单可能包含多个商品，用户可仅对其中符合条件的部分商品申请退货退款。

- 部分退货不等于其余商品被取消；
- 订单优惠、满减、优惠券、积分、运费及税费可能按比例重新计算；
- 若因退货导致订单不再满足当初免邮或活动门槛，平台可能从退款中扣回相应优惠差额（以适用法律及页面规则为准）；
- 套装、买赠、捆绑销售可能要求关联商品一并退回，否则仅退回可独立计价部分。

---

## 9. 无需退货的退款

在以下情形中，KickBazar 可能允许用户在不寄回商品的情况下获得退款或部分退款：

- 商品价值较低，退回成本明显高于商品价值；
- 用户已提供充分证据证明商品存在质量问题、错发或损坏；
- 包裹显示已送达但用户未收到，经核实属实；
- 缺件、少配件且平台判定无需退回剩余部分；
- 其他 KickBazar 基于风险控制与用户体验作出的合理决定。

是否适用无需退货退款，由 KickBazar 根据订单情况自主判断。获批后，请勿再将商品寄回，除非客服另有指示。

## 10. 质检标准

退货商品到达指定仓库或退货处理点后，KickBazar 或合作方将对商品进行检查和/或测试。

若发现商品不符合退货要求，例如但不限于：

- 已穿着、已洗涤、已使用；
- 损坏、污损、异味；
- 吊牌/卫生贴缺失或撕毁；
- 包装破损严重影响二次销售；
- 电子产品已激活或未清除个人数据；
- 缺少配件、说明书、赠品或部件；
- 寄回商品与申请信息不符；
- 空包裹或夹带无关物品；
- 因退回包装不当导致的运输损坏（非 KickBazar 或商家责任）；

则可能出现：

- 拒绝退款；
- 部分扣减退款金额以补偿商品价值损失；
- 将商品退回给用户（可能产生额外运费）；或
- 其他合理处理方式。

请确保寄回商品与退货申请一致，任何差异都可能导致延误或无法退款。

## 11. 退款方式

用户在提交申请时可选择（以页面实际可选选项为准）：

### 11.1 原路退回

退款退回至下单时的原始支付方式（银行卡、电子钱包、支付渠道等）。

### 11.2 KickBazar 余额 / 抵用金

- 到账通常快于原路退回；
- 一般无使用有效期（如有例外以余额规则页为准）；
- 通常仅可用于 KickBazar 购物，不能兑换现金；
- 一经发放，在适用法律允许范围内，通常不可再改回原支付方式。

### 11.3 货到付款（COD）订单的退款

对于货到付款订单：

- 若用户拒收且未支付，通常无需退款，订单按取消/退回处理；
- 若用户已支付 COD 款项后申请退货，退款可能退回至用户 KickBazar 余额，或按客服指引退回用户提供的收款账户；
- 具体方式以申请页展示及适用规则为准。

### 11.4 极速退款（如开通）

平台可能根据用户购物与信用记录，对部分订单提供“寄出即退”或“审核通过即退”的极速退款。

- 若商品未实际寄回、未通过质检，或存在滥用行为，KickBazar 可能通过原支付渠道扣回款项，或限制账户相关功能；
- 是否授予极速退款资格由 KickBazar 自主决定。

## 12. 退款金额与不予退还的费用

### 12.1 通常可退金额

符合条件的退款一般包括：

- 退回商品的实际支付价款；
- 因 KickBazar 或商家过错导致的退货所对应的配送费（如适用）；
- 购买时已由平台收取、且依法应退的相关税费（如适用）。

### 12.2 通常不予退还或可能扣减的项目

在非因 KickBazar 或商家过错的退货中，以下费用通常不予退还：

- 原始配送运费；
- 进口关税、VAT 或其他进口税费（如已产生且规则明确不退）；
- 运费险/保险费用（如有）；
- 签收服务费等附加费（如有）；
- 二次退货产生的退货运费；
- 因商品折旧、缺件、损坏而扣减的金额。

具体扣减明细将在退款处理时尽量向用户说明。

## 13. 退款时效

典型退货退款流程时效如下（均为预计时间，可能因物流、清关、节假日或金融机构而变化）：

| 环节 | 预计时间 |
| --- | --- |
| 退货物流运输 | 3–10 天（跨境退货可能更长） |
| 仓库签收 | 1–3 天 |
| 仓库质检 | 1–3 个工作日 |
| KickBazar 发起退款 | 质检通过后通常 1–3 个工作日 |
| 金融机构入账 | 原路退回通常 5–14 个工作日，最长可能约 30 天 |
| KickBazar 余额到账 | 通常更快，多为退款处理后较短时间内可用 |

您可在订单详情或退货详情中查看退款状态。若超过合理时间仍未到账，请先核对支付账户与账单，再联系客服并提供订单号。

## 14. 损坏、缺陷、错发、缺件

如果用户收到：

- 损坏商品；
- 存在质量问题的商品；
- 错误商品；
- 商品数量不足；
- 包裹内商品缺失；

经核实符合条件的，KickBazar 可能提供：

## 16. 换货

在平台开放换货功能的前提下，用户可对符合条件的商品申请换货（例如同款不同尺码/颜色，或同等价值替换）。

- 是否支持换货取决于库存、商品类型、商家及收货地区；
- 换货可能需要先退回原商品，质检通过后再发出替换商品；
- 如替换商品无库存，可改为退款；
- 跨境商品的换货时效通常长于孟加拉本地商品。

如页面未提供换货选项，用户可通过“退货退款”后重新下单完成更换。

## 17. 孟加拉本地商品与跨境商品的售后差异

### 17.1 孟加拉本地商品

本地库存或本地商家履约的商品，退货通常退回孟加拉境内仓库或商家，处理周期相对较短。

### 17.2 跨境商品

跨境商品的退货可能涉及：

1. 退货申请审核；
2. 退回至指定本地集货仓或跨境退货仓；
3. 必要的质检；
4. 国际回运或本地销毁/本地处置（由平台按规则决定）；
5. 退款处理。

因此，跨境商品的退货物流与退款到账时间可能长于本地商品。部分跨境场景下，平台可能更倾向于提供无需寄回的退款、部分退款或补发，以减少跨境回运成本与时效影响。

海关、监管检查及国际运输延误可能影响跨境退货进度，相关时间不完全受 KickBazar 控制。

## 18. 发货前取消与发货后售后

### 18.1 发货前取消

在订单或相关商品尚未进入无法取消的履约阶段前，用户可按平台提供的方式申请取消。成功取消的，已支付款项将按原支付方式或余额规则退回。

### 18.2 发货后

商品已经发货后，订单可能无法直接取消。如不再需要该商品，应在签收后按本政策申请退货（须符合退货条件）。

对于跨境商品，一旦进入国际运输、出口处理或其他跨境履约环节，取消限制可能更多，详见《配送政策》。

## 19. 拒收与退回

在适用法律及平台规则允许的情况下，用户可以在配送时拒绝接收商品。

- 因错发、严重破损、明显质量问题而拒收的，通常按平台/商家责任处理，符合条件的应予退款且不应因此限制合理售后；
- 对正常履约订单，如存在重复、恶意或明显不合理的拒收，KickBazar 可能在适用法律允许范围内限制该账户后续使用货到付款，或采取合理的配送与售后风险控制措施。

被拒收或多次投递失败后退回的商品，退款时效取决于包裹退回与入库进度。

## 20. 退货滥用与欺诈防范

为维护平台公平性与完整性，KickBazar 可能对退货行为进行综合分析。

可能被视为退货滥用或欺诈的行为包括但不限于：

- 寄回空包裹或无关物品；
- 调包、假冒伪劣替换；
- 故意伪造开箱视频、篡改标签或其他证据；
- 利用极速退款恶意骗取退款；
- 屡次无合理理由拒收 COD 订单；
- 其他严重违反诚信原则的行为。

一经核实，KickBazar 有权根据行为性质、频率与影响，采取合理措施，例如：

- 拒绝特定退货申请；
- 限制退货方式或极速退款资格；
- 限制 COD；
- 限制账户功能；
- 暂停或终止账户；
- 追回已退款项；
- 依法追究责任。

本政策任何内容均不限制用户行使适用法律规定的消费者权益。
