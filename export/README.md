# KickBazar WMS 原型（单文件）

**一个 HTML 包含全部交互**：Home、仓库/库区、SPU/SKU 库存（Admin 库存调整）、Inventory Record（详情/View 列/Outbound 子筛等）。

- 分辨率：1440×900  
- 使用：解压后双击 **`KickBazar-WMS.html`**，无需服务器  

## 下载

`KickBazar-WMS-Export.zip` 内仅含：

- `KickBazar-WMS.html` — 完整可交互原型  
- `README.md` — 本说明  

## 演示提示

1. 右上角 **Role** 切 Admin 后，在 **SPU/SKU inventory → SKU** 可做 **Inventory Adjustment**。  
2. **Record → Manual Adjustment** 可看到调整流水；**localStorage** 在同文件内生效。  
3. 开发多文件版见仓库 `prototype/` 目录。
